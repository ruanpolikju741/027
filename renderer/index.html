Exportar backup

Gera um arquivo com todo o catálogo (incluindo fotos/vídeos de cada item), usuários e histórico (o login do admin nunca é incluído). O arquivo fica protegido por uma senha que você escolhe agora — guarde essa senha, ela é pedida de volta na hora de importar. A senha pode ter letras, números e símbolos, com no mínimo 6 caracteres.

Importar backup

Disponível para os perfis Default e Admin, mas mesclar é exclusivo do Admin — o Default só pode substituir tudo. Escolha como aplicar o arquivo: O app volta pra tela de login depois de importar, já com as contas de login que vieram no arquivo.

Atenção: substituir tudo apaga o catálogo, usuários e histórico atuais e não pode ser desfeito.

Cadastre aqui uma conta de login pra cada pessoa que vai usar o app como Default — é o que substitui a antiga entrada livre sem senha nenhuma. A senha que você definir é temporária: assim que a pessoa entrar pela primeira vez (ou depois de um "Resetar senha"), o app já pede pra ela trocar por uma senha só dela, antes de liberar o resto do app.

Admin: marque "Admin" ao criar (ou use "Tornar Admin" na tabela) pra dar a uma conta os mesmos poderes que o Admin — editar tudo, quitar pendências, importar/exportar backup e gerenciar outras contas. Ela entra direto como Admin com o próprio usuário e senha. "Tirar Admin" devolve a conta pro Default na hora.
